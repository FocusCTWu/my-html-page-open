# 精神支持服務地圖
Mental Health Support Services Map in Taiwan

提供臺灣精神障礙者、精神病人及家庭照顧者相關社區支持服務資源的地圖查詢介面。

使用者可依：
- 使用情境
- 縣市
- 服務類型
- 地址類型

篩選合適的服務資源，並查看服務單位、地址、電話、服務區域及服務說明。

## 線上版本

> 部署網址：[待補]

目前提供三種底圖版本：

- NLSC EMAP6：繁體中文地名優先
- OpenFreeMap Liberty：資訊較完整的向量底圖
- OpenFreeMap Positron：較簡潔的向量底圖

正式版建議使用 NLSC EMAP6。

## 收錄服務

目前服務資訊涵蓋 12 類：

1. 社區居住
2. 社區日間作業設施
3. 精神障礙者協作模式服務據點
4. 提供日間照顧之身心障礙福利機構
5. 身心障礙者家庭托顧服務
6. 社區式日間照顧服務
7. 自立生活支持服務
8. 家庭照顧者支持服務
9. 家庭照顧者支持服務共融據點
10. 精神病病人及家庭支持服務
11. 精神病病人社區居住服務
12. 精神病病人自立生活支持服務

其中部分服務基於居住安全、隱私及個人資料保護，不公開實際服務地址，因此不以地圖點位呈現。

## 資料來源

服務資源資料由衛生福利部心理健康司彙整提供。

- 地圖資料版本：2026.10
- 服務說明資料時間：民國115年7月17日
- 地圖前端使用之資料檔：`data/community_support_map_data_v11.csv`

實際服務資格、收案條件及服務地點，仍請以各服務單位或地方主管機關最新公告為準。

## 地址類型

地圖區分：

- **服務據點**：原始資料明確提供之服務場所
- **聯絡地址**：機構或資源之聯絡地址，不一定是實際服務地點

聯絡地址在使用前建議先電話確認。

## 隱私說明

本網站：

- 不要求登入
- 不蒐集個人健康資料
- 不要求使用者輸入姓名、身分證字號或病歷資訊
- 使用者選擇的資格／使用情境只用於前端排序與提示

是否啟用瀏覽分析，應依實際部署環境另行公告。

## 技術

前端為靜態網站，主要使用：

- HTML / CSS / JavaScript

- MapLibre GL JS
